\# 🎓 Graduate Admission Prediction Using ANN



\## 📌 Overview



This project uses an Artificial Neural Network (ANN) to predict

the probability of graduate admission based on academic and

application-related features.



\## 🎯 Objective



The objective is to predict the `Chance of Admit` using:



\- GRE Score

\- TOEFL Score

\- University Rating

\- SOP

\- LOR

\- CGPA

\- Research Experience



\## 🧠 Machine Learning Approach



1\. Data Loading

2\. Exploratory Data Analysis

3\. Data Preprocessing

4\. Feature Selection

5\. Train-Test Split

6\. Feature Scaling

7\. Artificial Neural Network

8\. Model Training

9\. Model Evaluation



\## 🤖 Model



Artificial Neural Network using TensorFlow/Keras.



\## 📊 Evaluation Metrics



\- MAE

\- MSE

\- RMSE

\- R² Score



\## 🛠️ Technologies



\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Scikit-learn

\- TensorFlow

\- Keras
